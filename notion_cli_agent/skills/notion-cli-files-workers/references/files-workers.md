# Files and Workers reference

Current docs say:

- `ntn files create` can read stdin, output human-readable, `--plain`, or `--json`
- `--filename` and `--content-type` override inference
- `--external-url` imports a remote file asynchronously
- uploaded file ids can be attached with `ntn api` request bodies
- workers commands include new, deploy, list, get, create, delete, exec, capabilities list, tui
- workers sync/env/oauth/runs/webhooks each have dedicated subcommands
