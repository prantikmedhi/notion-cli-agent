# Notion CLI overview reference

Summarized from current Notion docs:

- install with `curl -fsSL https://ntn.dev | bash`
- `ntn login` opens browser auth
- CLI can make authenticated API requests, manage Workers, and upload files
- command reference documents global flags, auth commands, workers commands, api, datasources, pages, files, and diagnostics
- help docs describe CLI as usable by developers and AI coding agents
