# Pages reference

Current command reference says:

- `ntn pages get <page-id>` retrieves a page as Markdown
- `ntn pages create` creates a page from Markdown content
- `ntn pages edit <page-id>` updates content from Markdown
- `ntn pages trash <page-id>` trashes a page and supports `--yes`

Parent refs for create can target:

- `page:<id>`
- `database:<id>`
- `data-source:<id>`
